# Pokédex

A mini browser-based Pokédex with a retro handheld-console design. Search for a Pokémon by name or Pokédex number to display its front sprite, fetched from the [PokéAPI](https://pokeapi.co/).

## Features

- Search for Pokémon by name or Pokédex number
- Display the Pokémon's front sprite
- Responsive, retro-inspired Pokédex interface
- Built with HTML, CSS, and vanilla JavaScript

## Getting started

No build tools or dependencies are required.

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Enter a Pokémon name (for example, `pikachu`) or Pokédex number (for example, `25`) and select **SEARCH**.

An internet connection is required to retrieve data and sprites from PokéAPI.

## Project files

- `index.html` — page structure and search controls
- `style.css` — Pokédex appearance and layout
- `pokemon.js` — PokéAPI request and sprite display
